Os Granadeiros são especialistas em explosivos e arremessáveis, mestres da arte da destruição controlada. Treinados para maximizar o impacto de suas bombas e granadas, eles amplificam os efeitos devastadores de cada explosão. Dotados de uma resistência impressionante, os Granadeiros são capazes de suportar os próprios explosivos, permitindo que se movam pelo campo de batalha com ousadia e precisão.

## Habilidades
<br>
A cada level alcançado, o jogador poderá escolher uma habilidade dentre as opções disponíveis para o level em referência.

::

### Alquimista Experiente
*Habilidade Nível 2*

**Tipo:** :: Ativa
**Custo:**        :: 10 mana
**Cooldown:**     :: 60s

Ativamente, abre o menu de modificação de explosivos. Passivamente, suas poções consomem menos reagentes.

::

### Infusão Química
*Habilidade Nível 6*

**Tipo:** :: Passiva
**Custo:**        :: --
**Cooldown:**     :: --

Passivamente, desbloqueia a modificação do elemento das suas poções explosivas no menu de explosivos.

::

### Bombardeiro Eficiente
*Habilidade Nível 10*

**Tipo:** :: Passiva
**Custo:**        :: --
**Cooldown:**     :: --

Você sabe como tirar melhor proveito dos seus explosivos. Adicionalmente, você produz o dobro de explosivos.
