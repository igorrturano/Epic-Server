## Habilidades
<br>
A cada level alcançado, o jogador poderá escolher uma habilidade dentre as opções disponíveis para o level em referência.

::

### Conexão Divina
*Habilidade Nível 2*

**Tipo:** :: Ativa
**Custo:**        :: 10 stamina
**Cooldown:**     :: 120s

Você se conecta com sua divindade, canalizando seu poder. Cada religião oferece uma manifestação única dessa conexão. O uso de armaduras leves e médias não mais limitam seus gestos sagrados.

::

### Golpe Radiante
*Habilidade Nível 6*

**Tipo:** :: Ativa
**Custo:**        :: 20 stamina
**Cooldown:**     :: 180s

Você canaliza energia divina em um ataque devastador contra seus inimigos. Cada religião manifesta efeitos únicos.

::

### Aura Divina
*Habilidade Nível 10*

**Tipo:** :: Ativa
**Custo:**        :: 20 stamina
**Cooldown:**     :: 180s

Você se torna imune a doenças e pragas, mais resistente a venenos e não sente mais medo. Além disso, manifesta uma aura de proteção baseada na sua religião.

### Autoridade Divina
*Habilidade Nível 14*

**Tipo:** :: Ativa
**Custo:**        :: 40 stamina
**Cooldown:**     :: 300s

Você cria um terreno consagrado que fortalece aliados e enfraquece inimigos. Cada religião manifesta efeitos únicos nesse campo sagrado.


### Apoteose
*Habilidade Nível 20*

**Tipo:** :: Ativa
**Custo:**        :: 60 stamina | 50 mana
**Cooldown:**     :: 600s

Você ascende à manifestação divina. Suas magias divinas não consomem mana nem possuem delay. Cada religião concede um poder supremo ao seu campeão.
