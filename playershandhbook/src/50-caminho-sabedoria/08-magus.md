## Habilidades
<br>
A cada level alcançado, o jogador poderá escolher uma habilidade dentre as opções disponíveis para o level em referência.

::

### Determinação Arcana
*Habilidade Nível 2*

**Tipo:** :: Passiva
**Custo:**        :: --
**Cooldown:**     :: --

Quando estiver sem mana, suas magias custarão stamina.

::

### Salto Etéreo
*Habilidade Nível 6*

**Tipo:** :: Ativa
**Custo:**        :: 15 stamina
**Cooldown:**     :: 240s

Você abre um vértice temporal utilizando a energia arcana que paira sobre o mundo, dando a impressão de que teleportou para um local desejado dentro do seu alcance.

::

### Evocator
*Habilidade Nível 10*

**Tipo:** :: Passiva
**Custo:**        :: --
**Cooldown:**     :: --

Seus anos de estudo e dedicação aperfeiçoaram seus métodos, tornando suas magias de evocação mais difíceis de resistir.

### Prisão Dimensional
*Habilidade Nível 14*

**Tipo:** :: Ativa
**Custo:**        :: 25 stamina
**Cooldown:**     :: 600s

A Torre Infinita tem um local especial para guardar perturbadores dos planos. Você é capaz de enviar um para sua prisão pessoal e... libertá-lo quando quiser.

::

### Abrir Portais
*Habilidade Nível 20*

**Tipo:** :: Ativa
**Custo:**        :: 35 stamina
**Cooldown:**     :: 300s

Você é capaz de marcar alguns locais no mapa e utilizar sua energia arcana para teleportar até o local desejado. A duração do portal e a quantidade de locais marcados escalam com seu poder.
