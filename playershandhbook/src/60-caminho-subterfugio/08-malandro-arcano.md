## Habilidades
A cada level alcançado, o jogador poderá escolher uma habilidade dentre as opções disponíveis para o level em referência.

### Sensibilidade Arcana
*Habilidade Nível 2*

**Tipo:**     :: Passiva
**Custo:**    :: --
**Cooldown:** :: --

Você é capaz de conjurar truques mágicos simples e utilizar pergaminhos que normalmente exigiriam treinamento arcano formal.

::

### Ladrão de Magias
*Habilidade Nível 6*

**Tipo:**     :: Ativa
**Custo:**    :: 50 stamina
**Cooldown:** :: 300s

Você consegue devolver as magias conjuradas contra você, usando seus reflexos no lugar da vontade.

::

### Invocação do Caos
*Habilidade Nível 10*

**Tipo:**     :: Ativa
**Custo:**    :: 50 stamina
**Cooldown:** :: 900s

Você invoca uma criatura completamente aleatória — pode ser desde uma ovelha até um demônio, que de tão surpreso, lutará ao seu lado.

### Reaproveitar Pergaminho
*Habilidade Nível 14*

**Tipo:**     :: Passiva
**Custo:**    :: --
**Cooldown:** :: --

Você consegue usar os pergaminhos mais de uma vez antes de se deteriorarem, além de ganhar um bônus considerável em reflexos.

::

### Fantasma
*Habilidade Nível 20*

**Tipo:**     :: Ativa
**Custo:**    :: 50 stamina
**Cooldown:** :: 300s

Você manifesta uma forma arcana sobre seu corpo, passando completamente despercebido por criaturas hostis por algum tempo.
