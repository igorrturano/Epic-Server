## Habilidades
A cada level alcançado, o jogador poderá escolher uma habilidade dentre as opções disponíveis para o level em referência.

::

### Desbravador Nato
*Habilidade Nível 2*

**Tipo:**     :: Passiva
**Custo:**    :: --
**Cooldown:** :: --

Você consegue esquivar-se por completo de armadilhas quando bem sucedido num teste de reflexos, além de saber ler mapas de tesouro e abrir fechaduras mágicas.

::

### Distrair Oponentes
*Habilidade Nível 6*

**Tipo:**     :: Ativa
**Custo:**    :: 20 stamina
**Cooldown:** :: 90s

Você cria uma distração que paralisa por alguns segundos os inimigos imediatamente ao seu redor.

::

### Sempre Alerta
*Habilidade Nível 10*

**Tipo:**     :: Passiva
**Custo:**    :: --
**Cooldown:** :: --

Você é imune a ataques surpresa e ganha um bônus para detectar criaturas escondidas.
