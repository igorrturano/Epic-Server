## Habilidades
A cada level alcançado, o jogador poderá escolher uma habilidade dentre as opções disponíveis para o level em referência.
<br><br>

### Movimentação Graciosa
*Habilidade Nível 2*

**Tipo:**     :: Ativa
**Custo:**    :: 20 stamina
**Cooldown:** :: 10s

Ao ativar, você se esquiva do próximo golpe. Enquanto tiver esta habilidade, você recebe um bônus permanente em acerto e esquiva.

::

### Reflexo Estratégico
*Habilidade Nível 6*

**Tipo:**     :: Ativa
**Custo:**    :: 30 stamina
**Cooldown:** :: 20s

Passivamente, empunhando um *buckler*, você usa *Tactics* no lugar de *Parry* para aparar. Ao ativar, você regenera stamina por um período.

::

### Desmoralizar
*Habilidade Nível 10*

**Tipo:**     :: Ativa
**Custo:**    :: 15 stamina
**Cooldown:** :: 120s

Você convida o alvo a te atacar de forma tão desmoralizante que ele sofre redutores de acerto.

### Finta Esgrimista
*Habilidade Nível 14*

**Tipo:**     :: Ativa
**Custo:**    :: 30 stamina
**Cooldown:** :: 180s

Enquanto nessa postura, todo ataque recebido é imediatamente contra-atacado.

::

### Mestre Duelista
*Habilidade Nível 20*

**Tipo:**     :: Ativa
**Custo:**    :: 30 stamina
**Cooldown:** :: 180s

Por alguns segundos, você rola novamente cada ataque que errar, recusando-se a falhar.
