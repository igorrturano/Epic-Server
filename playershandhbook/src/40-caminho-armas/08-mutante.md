## Habilidades
<br>
A cada level alcançado, o jogador poderá escolher uma habilidade dentre as opções disponíveis para o level em referência.

::

### Forma Adaptável
*Habilidade Nível 2*

**Tipo:** :: Ativa
**Custo:**        :: 20 stamina
**Cooldown:**     :: 180s

Alterando seu corpo através de mutações, você consegue aumentar uma resistência à sua escolha.

::

### Óleo do Caçador
*Habilidade Nível 6*

**Tipo:** :: Ativa
**Custo:**        :: 20 stamina
**Cooldown:**     :: 600s

Você aprende a criar óleos para armas que ferem com mais eficácia determinados tipos de alvos. Adicionalmente, você recebe um bônus de acerto baseado na sua perícia *Science*.

::

### Impulso Metabólico
*Habilidade Nível 10*

**Tipo:** :: Passiva
**Custo:**        :: --
**Cooldown:**     :: --

Você fortaleceu seu metabolismo através de mutações alquímicas. Poções de aprimoramento duram mais e concedem benefícios maiores para você.

### Transmutar
*Habilidade Nível 14*

**Tipo:** :: Ativa
**Custo:**        :: 5 stamina
**Cooldown:**     :: 10s

Eureka! Você aprende a manusear a fórmula 90, além de aprender a criar resinas elementais para armas.

::

### Mutagênicos
*Habilidade Nível 20*

**Tipo:** :: Ativa
**Custo:**        :: 5 mana
**Cooldown:**     :: 10s

Você descobriu uma fórmula secreta para criar mutagênicos que alteram seu metabolismo. Ao ativar, escolha um aprimoramento em destreza, força ou inteligência (que também reforça a vitalidade ligada a esse atributo); ativar de novo desfaz o efeito.
